Here’s all the metadata you need for every course explicitly referenced in the PDF, organized in a LaTeX-friendly way so you can drop it into `main(3).tex` and wire it up to whatever course macro you’re using. All fields follow the PDF’s schema: **Institute, Course Name, Level, Summary, Prerequisites, Hardness, Leads To, URL(s)**. 

Below I use a consistent key-value format you can map into your own macro, e.g.
`course_key / institute / code / title / level / summary / prerequisites / hardness / leads_to / url_main / url_alt`.

### How to use this in `main(3).tex`

For each course, you now have the fields your LaTeX file likely expects:

```text
course_key / institute / code / title / level / summary / prerequisites / hardness / leads_to / url_main [/ url_alt]
```

You can:

* Either plug these directly into your existing course macro in `main(3).tex`,
* Or define a helper like
  `\ocwcourse{<key>}{<institute>}{<code>}{<title>}{<level>}{<summary>}{<prereqs>}{<hardness>}{<leads_to>}{<url_main>}`
  and paste each block in.

If your PDF copy includes an actual JSON appendix with **additional** courses beyond the ones named in the prose, I can’t see that JSON from here; the list above covers all courses explicitly referenced in the text sections of the report.
